# fullstory-guides-and-surveys-swift-package-ios

Swift package artifacts for the Fullstory Guides and Surveys SDK, for iOS mobile apps. Email mobile-support@fullstory.com for additional help.

## Installation

In Xcode, choose **File > Add Package Dependencies...** and enter this repository's URL:

```
https://github.com/fullstorydev/fullstory-guides-and-surveys-swift-package-ios
```

Or add it to your `Package.swift` dependencies:

```swift
.package(url: "https://github.com/fullstorydev/fullstory-guides-and-surveys-swift-package-ios", from: "0.1.0")
```

Then `import FullstoryGuidesAndSurveys` in your code.

## Requirements

- iOS 17.0+
